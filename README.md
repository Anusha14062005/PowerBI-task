Problem Statement

The sales dataset had duplicate records, incorrect data types, and missing analytical columns, making sales analysis difficult.

Solution

Using Power Query, I:

Corrected data types and removed duplicates.
Created Year, Month, Quarter, and Profit columns.
Classified sales as High, Medium, or Low.
Filtered South Region data and sorted sales.
Used Advanced Editor and Group By for category-wise sales analysis.

Result

The raw data was successfully cleaned, transformed, and organized for effective sales analysis.
